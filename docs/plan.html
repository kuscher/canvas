Canvas

A full-featured, open-source image editor for every Googlebook, Intel and Snapdragon, as one ordinary app. It is built from Patchy, a Photoshop-style editor in C++ and Qt 6, using Qt's own Android support. The raw port comes first, then the phases that make it feel at home.

What you give up compared with GIMP

  • XCF files.
  • 16- and 32-bit editing, and CMYK editing.
  • GEGL and G'MIC filters, and Script-Fu and Python plug-ins. Patchy scripts in JavaScript instead.
  • 8BF plug-ins, which are Windows-only upstream.

The risk you take on

  • Patchy is four months old, has one maintainer, and was built with heavy AI help.
  • It releases every few days: 0.98, 0.99 and 1.00 came out within three days.
  • We limit the risk by pinning a release tag and keeping our changes as patches. The bigger step would be getting Android support accepted upstream.

What the port has to handle

From reading Patchy's code at v1.00

  • The build. CMake and Qt 6, with branches for Windows, macOS, Linux and the web, but none for Android yet. On Android, Qt also counts as Linux, so each Linux-only code path gets checked.
  • Features to switch off. These are Windows- or desktop-only, or need the internet, and the web build already switches most of them off: legacy 8BF plug-ins, scanner import, the update checker, the single-instance and AI-control servers, and helper programs.
  • Printing. Patchy makes a PDF, and Canvas hands it to Android's print dialog, the same way the web build handles printing.
  • Files. Patchy's core works with file paths. Canvas copies the file you pick into the app's storage and copies saves back, so Ctrl+S goes to the same file. Recent files keep working, and no broad storage permission is needed.
  • Desktop behaviour. The menu bar stays a real menu bar instead of Android's options menu. The window resizes freely without restarting and never forces full screen. Dialogs and floating panels open inside the app window; that's a Qt-on-Android limit.
  • Pen. Patchy already uses pressure from tablet events. Tilt and eraser get checked on the device.
  • Fonts. PSD text expects Arial and Times. Canvas bundles the web build's metric-compatible fonts and relies on Android's own fonts for CJK.
  • PDF import. Qt PDF isn't published for Android. Patchy already copes with that: PDF export still works.
Phases

Raw port first, then make it feel native

0

Build and a first window

  • Pin Patchy v1.00 and keep our changes as a folder of patches, the MixxxBook and OfficeBook pattern.
  • CI: prebuilt Qt 6.11 for Android plus the NDK. One build makes one APK for both chips, and ./cv fetch signs it.
  • First patches: an Android build target, the manifest (resizable, no internet permission, icon, caption colour), the desktop menu bar, and the desktop-only features switched off.

Done when Patchy opens on your HP in a resizable window, and you can make a new image and paint on it.

1

The raw port → v0.1

  • Files: Open, Save, Save As and Export through Android's picker; saving back in place; recent files; "Open with Canvas" from Files; recovery when Android stops the app.
  • Input: pen pressure (plus tilt and eraser if available), right-click, wheel and trackpad scrolling, shortcuts, and text copy and paste.
  • Look: sharp fractional scaling on the HP (1.125×) and ASUS (1.625×), light and dark themes following the system, and bundled PSD fonts.
  • Print: through Android's print dialog.
  • Memory: checked against Android 17's memory limits with a big PSD.
  • Both chips: arm64 on the HP, x86_64 on the ASUS, plus a CI smoke test.
  • Licences: notices and sources ship with the release.

Done when, on both Googlebooks: a JPEG, PNG and layered PSD open from Files; heal, clone, adjustment layers and text work; the PSD saves back in place; PNG export and printing work; the pen paints with pressure; and settings survive a restart.

2

At home on a Googlebook

  • Images on the clipboard both ways, and dragging pictures in from Files.
  • Pinch to zoom and two-finger rotate on the trackpad.
  • HEIC and AVIF through Android's own decoders.
  • Import from camera, replacing scanner import. Share and "Send to" other apps.
  • Launcher shortcuts: New image, Paste as new image, and recent files.
  • A Googlebook theme option, and a shortcut list on Meta + /.
3

Upstream and polish

  • Offer the Android port to Patchy if you want (question 2). After that, a rebase script keeps Canvas in step with Patchy's fast releases.
  • Lower pen latency and pen-button mapping.
